Welcome to the Real Effort Task - game

Exact game is an experimental task designed to measure participants' real effort through an accurate text game activity. In this task, participants are shown a text or sequence of characters and are required to type it exactly as displayed. The performance can be evaluated based on the amount and accuracy of the game they complete within a given time, also this task will have a limited amount of time to complete as many game tasks as possible.
